# Malayalam radio tuner

Ente Radio’s HTTPS endpoint was taken from its official homepage player and checked on 9 October 2026. Live broadcasters can change their streams or go offline independently of this static portfolio.

The first ready click, Enter or driving input attempts Ente in the same trusted event. An explicit power-off preference is preserved. The tuner uses native media playback so station CORS policies do not need to permit Web Audio. Static is a separate, quiet synthesized sound; it fades on `playing`, returns on `waiting`, and ends on failure or the 14-second deadline. A generation token cancels stale station callbacks when seeking rapidly. Arrow keys seek and adjust volume; Enter switches power.

The music shop has its own local drum instrument. It ducks the current radio while playing and restores the user’s volume when stopped or closed. It does not replace the radio source or override the power preference.

The curated stations remain available if the optional Radio Browser directory cannot be reached. Directory entries must be public HTTPS URLs, report a successful recent check, use a supported audio codec and identify Malayalam. Private/local destinations and unsupported playlists are rejected. Radio Browser is a directory, not a licence for the broadcast music. Station links and all project links remain available without playback.

Browser tests use generated PCM fixtures for successful, slow, failed, timed-out and rapidly replaced stations. A separate live broadcast probe is recorded in VALIDATION.md. No broadcast audio is copied into the repository.
